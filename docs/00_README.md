## Qué no se incorpora literalmente

No se consideran especificaciones definitivas las afirmaciones
legales/contractuales concretas de los documentos antiguos. Antes de
utilizarlas para decisiones comerciales, licencias de datos, contratos o
tratamiento de datos reales deben verificarse con fuentes actualizadas y
asesoramiento profesional cuando corresponda.

## Regla

Los documentos antiguos no sustituyen a los nuevos: se han usado como
fuente para construir esta V2.
